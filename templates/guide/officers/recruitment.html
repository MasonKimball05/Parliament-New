1 Recruitment in Parliament

Parliament's recruitment tools cover the full funnel from initial interest sign-ups through rush event management to the final pledge roster. The Recruitment Committee (VPR + recruitment chairs) owns this workflow.

📝
Sign-Ups
Interest form submissions from rushees
📅
Rush Events
Events with rush-specific RSVP tracking
🏠
Pledge Roster
Accepted bids + account creation

2 Managing Sign-Ups

When a rushee fills out the interest form, their submission appears in Recruitment → Manage Sign-Ups. Each entry shows contact info, availability, and any notes they submitted.

1

Review submissions

Filter by date, status, or search by name. Click any row to see full submission details.

2

Add internal notes

Recruitment chairs can attach private notes to any sign-up entry — visible only to committee members, never to the rushee.

3

Export the roster

Use the CSV export button to download the full sign-up list for offline review or distribution to chapter members.

Announcement emails: When a sign-up form is published, a chapter-wide email announcement is sent automatically — excluding Advisors. No manual action needed.

3 Rush Events

Rush events are regular chapter events with rush-mode enabled. When rush mode is on, the event RSVP list is separated into member RSVPs and rushee RSVPs, and attendance tracking notes rush-specific data.

Creating a rush event

  1. Go to Events → Create Event.
  2. Fill in the standard event fields (title, date, location).
  3. Toggle Rush Event on in the event options.
  4. Save — the event appears on the chapter calendar and in the Recruitment dashboard.

RSVP reminders: Rush events send RSVP reminder emails at the configured lead times. Double-check the reminder timing when creating the event — reminder fields default to chapter settings but can be overridden per-event.

4 Accepting Bids & Creating Pledge Accounts

After bid day, the VPR (or an admin) creates Parliament accounts for accepted pledges. This is done in Admin → User Management.

1

Create user accounts

Use Bulk Add Members to import the pledge list at once, or add them individually. Set member_type = Pledge.

2

Send welcome emails

After accounts are created, use the bulk email tool to send login instructions to the new pledges.

3

Notify the Education Committee

The VPE needs the final pledge list to set up tasks, quizzes, and the pledge education schedule in Parliament. Hand off the list via the recruitment dashboard or directly.

5 Who Can See Recruitment Data?

Recruitment data is sensitive — only authorized committee members can access it.

Full access: VPR, recruitment chairs, admins
Rush events only: All chapter officers (to help run events)
No access: Regular members, pledges, alumni
