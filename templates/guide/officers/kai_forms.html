Kai Form Customization

Build custom forms for Kai report submissions

Access Required

Kai form customization is only available to Kai Committee chairs and designated administrators. Contact your chapter's Kai Chair if you need to make changes.

1 Form Builder Overview

The Kai form builder lets you customize what information is collected when members submit reports. This ensures you gather the details needed for fair deliberation.

Form builder features:

  • Drag-and-drop field ordering
  • Multiple field types (text, dropdown, checkbox, etc.)
  • Required vs optional field settings
  • Custom help text for each field
  • Live preview of your form

2 Available Field Types

Choose from various field types to collect the information you need.

Short Text

Single line text input for brief answers

Long Text

Multi-line text area for detailed descriptions

Dropdown

Select one option from a predefined list

Checkboxes

Select multiple options from a list

Date

Date picker for incident dates

Member Select

Select a member from the chapter roster

3 Adding and Editing Fields

To add a new field:

  1. Click "Add Field" in the form builder
  2. Select the field type
  3. Enter the field label (question text)
  4. Add optional help text
  5. Set whether the field is required
  6. For dropdowns/checkboxes, add the options
  7. Click "Save Field"

To reorder fields:

  • Click and drag the handle on the left side of any field
  • Drop it in the desired position
  • Changes are saved automatically

4 Best Practices

Be Clear and Specific

Write questions that are easy to understand. Avoid jargon.

Use Help Text

Add help text to explain what information you're looking for.

Only Require Essentials

Only mark fields as required if they're truly necessary.

Test Your Form

Use the preview feature to test your form before publishing.

Caution: Changing the form structure may affect how existing reports display. Review the impact before making significant changes.
