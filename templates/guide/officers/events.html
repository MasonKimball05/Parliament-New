Events Management

Learn how to create and manage chapter events

Quick Actions

Create Event Manage Events

1 Creating Events

To create a new event, navigate to Officers → Manage Events and click the "Create Event" button.

Event Details

  • Title: A clear, descriptive name for the event
  • Date & Time: When the event will take place
  • Location: Where the event will be held
  • Description: Additional details about the event
  • Event Type: Categorize the event (chapter, social, service, etc.)

2 Setting Attendance Requirements

When creating an event, you can set attendance requirements to specify who is required to attend.

Mandatory

Attendance is required. Members will be marked absent if they don't attend without an approved excuse.

Optional

Attendance is encouraged but not required. No penalty for not attending.

Tip: You can also specify which member types are required to attend (e.g., only active members, or including pledges).

3 Managing Existing Events

From the event management page, you can perform various actions on existing events:

Edit Event

Update event details, time, location, or attendance requirements

Take Attendance

Mark members as present, absent, or excused for the event

Delete Event

Remove an event (this action cannot be undone)

4 Viewing Attendance Reports

After an event, you can view attendance records to see who attended, was absent, or excused.
