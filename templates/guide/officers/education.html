1 The Education Committee's Role

The Education Committee (VPE + education chairs) owns the pledge education program. In Parliament, this means: creating tasks and quizzes, monitoring pledge progress, reviewing quiz submissions, and marking tasks complete.

Your workflow

  1. Create tasks and quizzes for the semester
  2. Activate them at the right point in the program
  3. Monitor progress on the overview dashboard
  4. Review quiz answers and mark tasks done

Who can manage tasks?

  • ✅ VPE — full create/edit/delete access
  • ✅ Education chairs — review and mark tasks
  • ✅ Admins — full access
  • ❌ Other officers — read-only progress view

2 Creating Tasks

Go to Pledge Education → Manage Tasks → New Task. Every task has a type, a phase, and a required/optional flag.

Field Notes
Type Task, Quiz, Milestone, Reading. Quiz enables the answer submission form.
Phase General, Phase 1, Phase 2, or Phase 3. Tasks are grouped by phase on pledge dashboards.
Required Required tasks must be completed for initiation. Optional tasks add to point totals.
Assigned To Leave blank to assign to all pledges, or select specific pledges.
Active Inactive tasks don't appear on pledge dashboards. Use this to schedule tasks in advance.

Tip: Create all your tasks for the semester upfront, then toggle them active progressively as the semester moves forward. Pledges can't see inactive tasks.

3 Setting Up Quizzes

Quizzes are tasks with type = Quiz. After creating the task, add questions to it from the task detail page.

1

Create a Quiz task

Same form as any task — set type to "Quiz" and leave it inactive while you're setting up questions.

2

Add questions

Open the task and click "Add Question." Questions are free-response (text answers). Add as many as needed. Drag to reorder.

3

Activate when ready

Toggle the task to Active. Pledges will immediately see the quiz with a "Take Quiz" button. Once a pledge submits, their answers are locked.

Character limit: Quiz answers are capped at 2,000 characters per question. Tell pledges to be concise — bullet-point answers are fine if they cover the material.

4 Reviewing Quiz Submissions

When a pledge submits a quiz, it lands in your review queue (Pledge Education → Pending Reviews). Education chairs can review submissions and mark them complete or incomplete.

Mark Complete

The task is credited to the pledge. Hours and completion credit are applied immediately. You can optionally leave a reviewer note.

Mark Incomplete

The pledge is notified. Leave a reviewer note explaining what they need to fix — this note is visible to the pledge on their task page. The pledge will need to re-submit through you.

Quizzes can only be submitted once by pledges. If a submission needs to be reset, an admin can clear it from the task detail page.

5 Monitoring Pledge Progress

The Pledge Progress Overview shows all pledges in a matrix — rows are pledges, columns are required tasks. At a glance you can see who's behind and where the bottlenecks are.

Reading the matrix

  • 🟢 Green — completed
  • 🟡 Yellow — awaiting review
  • 🔴 Red — incomplete or not started

Drill down

Click any pledge's name to open their full task list and see every task with status and reviewer notes.

Before initiation: Run a final check on the progress overview to confirm all required tasks are green for every pledge. Missing a required task blocks initiation eligibility.
