Activity Logs

View audit trails and system activity

Why Activity Logs Matter

Activity logs provide transparency and accountability. They help you understand who did what and when, which is essential for governance and resolving questions.

1 What Gets Logged

Parliament automatically logs important actions performed by officers and the system.

Member Actions

  • Member added/removed
  • Member type changed
  • Role assignments
  • Profile updates

Legislation

  • Legislation created
  • Voting opened/closed
  • Vote results recorded
  • Legislation status changes

Events

  • Event created/edited
  • Attendance recorded
  • Excuses approved/denied
  • Event deleted

System

  • Settings changed
  • Committee modifications
  • Officer role changes
  • Admin actions

2 Accessing Activity Logs

Activity logs are available to officers and advisors through the admin dashboard.

To access:

  1. Go to Admin or Officers
  2. Select "Activity Logs"
  3. Browse or filter the log entries

3 Understanding Log Entries

Each log entry contains key information about the action.

Log entry includes:

  • Timestamp: When the action occurred
  • User: Who performed the action
  • Action Type: What kind of action (create, update, delete)
  • Target: What was affected (member, event, etc.)
  • Details: Specific information about changes made

4 Filtering and Searching

Use filters to find specific activity entries quickly.

Filter by:

  • Date range
  • User who performed action
  • Action type
  • Category (members, events, etc.)

Common searches:

  • "Who changed this member's status?"
  • "When was this event modified?"
  • "What did this officer do today?"
  • "Show all deletions this month"

Privacy: Activity logs are only accessible to officers and advisors. Regular members cannot view the activity log.
