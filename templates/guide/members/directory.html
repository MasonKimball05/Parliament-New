Member Directory

Find and connect with chapter members

Quick Actions

View Directory

1 Browsing the Directory

The member directory shows all chapter members. Navigate to Members from the main menu to access it.

Information displayed:

  • Name: Member's preferred name and profile picture
  • Role: Officer position, if applicable
  • Member Type: Active, Pledge, Alumni, etc.
  • Contact: Email and phone (if shared)

2 Searching for Members

Use the search bar at the top of the directory to quickly find specific members.

You can search by:

  • First or last name
  • Preferred name or nickname
  • Officer position

3 Filtering Members

Use filters to narrow down the directory to specific groups of members.

By Member Type

  • Active Members
  • Pledges
  • Alumni
  • Inactive

By Role

  • Officers
  • Committee Chairs
  • Committee Members
  • General Members

4 Viewing Member Profiles

Click on any member's name or photo to view their full profile.

Profile information includes:

  • Full name and profile picture
  • Contact information (email, phone if shared)
  • Member type and status
  • Committee memberships
  • Officer roles (current and past)

Privacy: The directory is only visible to chapter members. Contact information shared here should only be used for chapter-related communication.
