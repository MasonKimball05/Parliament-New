About emergency lockdown

A last-resort measure that blocks all access to the site except from explicitly allowed addresses.

When to use

  • Active security breach detected
  • Mass credential compromise suspected
  • System under active attack
  • Emergency maintenance required

What happens

Everyone trying to reach any page sees a maintenance message. Only allowed IPs can sign in.
