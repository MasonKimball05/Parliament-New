{% load admin_v2_tags %}{% comment %} Base for a slide-out panel fragment (Azure-style blade). A detail view renders a template extending this when asked with ?panel=1 (see src/admin_console.py `wants_panel` / `panel_response`); panel.js fetches it and drops it into the frame's #ac-panel. Opened directly (no JS, a new tab, a shared link) the same URL without ?panel=1 is the full page. Blocks: panel_avatar optional leading avatar/icon panel_title the item's name (an

, focused when the panel opens) panel_subtitle one line under it panel_full_url link for "open full page" (default: this path) panel_actions buttons / POST forms under the header panel_tabs optional tabs: buttons with data-ac-tab and aria-controls, inside
panel_body the content; with tabs, one
each (all but the first `hidden`) No script tags here: they would not run (the fragment is inserted as HTML). Forms work as usual (POST, data-confirm) and their redirects load full pages. {% endcomment %}
