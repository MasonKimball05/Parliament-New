About Honeypots

Honeypot endpoints are fake URLs that legitimate users would never access. They mimic common attack targets (like WordPress admin, phpMyAdmin, etc.). Any access to these endpoints is suspicious and triggers an automatic IP ban and security alert. This helps identify and block attackers before they can find real vulnerabilities.
