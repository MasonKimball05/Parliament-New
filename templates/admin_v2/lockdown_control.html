About Emergency Lockdown

Emergency lockdown is a last-resort security measure that blocks all access to the system except from explicitly whitelisted IP addresses.

When to use:

  • Active security breach detected
  • Mass credential compromise suspected
  • System under active attack
  • Emergency maintenance required

What happens: All users attempting to access any page will see a maintenance message. Only IPs in the whitelist can log in and access the system.
