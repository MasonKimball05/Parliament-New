{% comment %} One status vocabulary — v3.21.0. ⚠️ WHY. The same four completion states were rendered three different ways: SVG icons on the pledge page, emoji in the chair's grid, ad-hoc coloured pills elsewhere. Same information, three visual languages, so a chair and a pledge looking at the same fact saw different things. Params: `status` — a PledgeTaskCompletion status, an EducationMeetingAttendance status, or empty/None for "not started". `label` — optional override; defaults to a sensible word per status. Colours are shared with the meeting-attendance chips deliberately: green means done/present everywhere in this app, amber means waiting, red means a problem. {% endcomment %} {% if label %}{{ label }} {% elif status == 'completed' %}Completed {% elif status == 'incomplete' %}Incomplete {% elif status == 'pending' %}Awaiting review {% elif status == 'waived' %}Waived {% elif status == 'present' %}Present {% elif status == 'late' %}Late {% elif status == 'excused' %}Excused {% elif status == 'absent' %}Absent {% else %}Not started{% endif %}
