# v2.30.0 — Chat Overhaul + PWA

**Release date:** 2026-06-02

## Summary

Major quality-of-life update to the chat system, plus Progressive Web App (PWA) support. Push notifications now fire when someone sends a message and you're not actively viewing the channel — and they respect a new per-channel notification preference (All Messages / @Mentions Only / None). @mentions using `@username` are now supported with autocomplete, highlighted in blue in rendered messages, and used to target push notifications. A nav badge shows unread counts without opening chat. URLs autolink. Line breaks render. Old history loads on demand. Parliament can now be installed as a standalone desktop or mobile app via any modern browser.

---

## New Features

### Push Notifications for New Messages
When a message is sent in a channel, Parliament now dispatches a Web Push notification to every channel member who:
- Has previously visited the channel (has a read receipt)
- Is **not** currently active in the channel (hasn't polled in the last 10 seconds)
- Is not the sender
- Has push notifications enabled for chat (`push_chat` preference, defaults to on)

The notification includes the channel name (`#channel-name`), sender name, and a preview of the message. Tapping the notification opens the channel directly. Failures never block the message send — push is fire-and-forget.

### Unread Chat Badge in Nav
The "Chats" link in the nav now shows a red badge with the total count of unread messages across all channels the user has visited. Counts above 99 show as 99. The badge disappears the moment you open a channel (cache is invalidated on channel view and on every poll). Both desktop and mobile navs updated.

### URL Autolinking in Messages
URLs (`http://` and `https://`) in message text are now rendered as clickable links. Links open in a new tab with `rel="noopener noreferrer"`. Applied to both server-rendered initial messages and messages received via polling. HTML injection is not possible — non-URL text is still HTML-escaped before rendering.

### Line Breaks in Messages
Newlines in messages now render as `<br>` breaks. Multi-line messages no longer collapse into a single line.

### Load Older Messages
Channels with more than 50 messages now show a "Load older messages" button at the top of the chat window. Clicking it fetches the previous 50 messages and prepends them above the current view, preserving your scroll position. The button hides automatically when you reach the beginning of history.

### @Mentions with Autocomplete
Type `@` in the message input to open an autocomplete dropdown showing channel members. Select a member or finish typing their username. The mention is stored as `@username` in the message text. In rendered messages, `@username` patterns are highlighted with a blue badge. Only valid active-member usernames trigger highlighting.

### Per-Channel Notification Preferences
A bell icon in the top-right of each channel lets each user choose their notification level for that channel independently:
- **All Messages** (default) — push for every new message
- **@Mentions Only** — push only when your username is @mentioned
- **None** — no push notifications for this channel

Preference is saved via `POST /api/channel/{id}/notification-pref/` and stored in the new `ChatNotificationPreference` model. The button shows the current setting and updates immediately on change. The `_dispatch_chat_push` function loads all per-channel prefs in a single query before dispatching.

### PWA — Install as a Desktop or Mobile App
Parliament can now be installed as a standalone app on any device:
- **Desktop (Chrome/Edge):** An install icon appears in the address bar after visiting the site. Clicking it installs Parliament as a standalone window — no browser chrome, own entry in the dock/taskbar, Beta blue title bar.
- **iOS Safari:** Share → "Add to Home Screen" → launches fullscreen with the coat of arms icon.
- **Android Chrome:** Same browser install prompt as desktop.

Changes made:
- `static/manifest.json`: Added `scope`, `display_override` (`window-controls-overlay` for Chromium title bar blending), corrected `orientation` to `any`, synced `theme_color` to `#003DA5`, added explicit `192x192`/`512x512`/`1024x1024` icon entries pointing at the existing coat of arms PNG.
- `static/js/service-worker.js`: Added `install`/`activate` handlers (`skipWaiting` + `clients.claim()` so updates take effect immediately) and a no-op `fetch` handler (required by Chrome for the install prompt).
- `templates/base.html`: Synced `<meta name="theme-color">` to `#003DA5`.

## Technical Details

- `src/models/chat.py`: Added `ChatNotificationPreference` model with `unique_user_channel_notif_pref` constraint; `NOTIFICATION_LEVELS` choices: `all`, `mentions`, `none`; no boolean fields — level is a CharField
- `src/migrations/0185_chat_notification_preference.py`: Migration for above
- `src/view/chat/channel_chat.py`: Added `_parse_mentions()` to extract @username patterns; rewrote `_dispatch_chat_push()` to accept `mentioned_pks`, load per-channel prefs in one query, and respect level (all/mentions/none); added `get_channel_members` endpoint (returns member list for autocomplete); added `set_channel_notification_pref` endpoint; `send_channel_message` now parses mentions before dispatching push; `channel_chat` view loads current `notif_pref` and passes `notif_pref_choices` to template; `get_channel_messages` supports `?before=<timestamp>` for history pagination; both views invalidate `chat_unread_{pk}` cache on read
- `src/models/users.py`: Added `push_chat` property to `UserPreferences` (reads `prefs['push']['chat']`, defaults `True`) — no migration needed
- `src/context_processors.py`: `notifications()` now also computes `unread_chat_count` (sum of `get_unread_count()` across user's ChatReadReceipts, cached 30s, capped at 99)
- `templates/base.html`: Chats nav link now shows `unread_chat_count` badge (desktop and mobile); `theme-color` meta synced to `#003DA5`
- `templates/chat/channel.html`: `renderMessageText()` now handles URLs, @mentions (highlighted), and newlines in one pass; added @mention autocomplete (lazy-loads members on first `@`, filters as you type, inserts on click/select); added notification preference bell dropdown (shows current pref, updates via JS/POST); initial messages processed via `DOMContentLoaded`; `appendMessage()` updated; added `prependMessage()` and `loadOlderMessages()`; `has_more_messages` and `oldestMessageTimestamp` for pagination
