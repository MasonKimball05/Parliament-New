# v3.1.0 — Event Push Reminder Notifications

**Release Date:** 2026-06-05
**Status:** Deployed

---

## Summary

Adds up to two push notification reminders per calendar event. Officers independently enable each reminder and choose how far in advance to send it. A global on/off setting and default lead time are configurable in Admin v2. A Celery Beat task fires every 15 minutes to dispatch reminders on schedule.

## What's New

- **Up to 2 reminders per event** — first and second reminder each have an independent toggle and hours-before lead time
- **Admin v2 global controls** — enable/disable all reminders and set the default lead time
- **Celery task** — `send_event_reminder_pushes` runs every 15 minutes, handles both reminder slots per event, marks each sent independently
- **Respects existing controls** — honors the `push_events` feature flag, `event_reminders_enabled` SiteSetting, and per-user push opt-out

## Changes

### Models
- **`src/models/events.py`**
  - Added `reminder_1_enabled` (BooleanField, default False)
  - Added `reminder_1_hours_before` (PositiveIntegerField, default 24)
  - Added `reminder_1_sent_at` (DateTimeField, null=True)
  - Added `reminder_2_enabled` (BooleanField, default False)
  - Added `reminder_2_hours_before` (PositiveIntegerField, default 1)
  - Added `reminder_2_sent_at` (DateTimeField, null=True)

### Migrations
- **`src/migrations/0196_event_reminder_fields.py`** — adds all six reminder fields to the `Event` table
- **`src/migrations/0197_event_reminder_logs.py`** — creates `EventReminderLog` and `EventReminderRecipient` tables

### Forms
- **`src/forms.py`** — `EventForm` now includes all four editable reminder fields (`reminder_1_enabled`, `reminder_1_hours_before`, `reminder_2_enabled`, `reminder_2_hours_before`) with widgets and labels

### Views
- **`src/view/admin_v2.py`** (`admin_v2_dashboard`)
  - Seeds `event_reminders_enabled` (boolean) and `event_reminder_default_hours` (integer) SiteSettings on first load
  - Passes `event_reminder_settings` queryset to template context

### Templates
- **`templates/admin_v2/dashboard.html`**
  - Added "Event Reminder Settings" subsection in the Push Notifications card
  - Global enable/disable dropdown and default hours input, each with a Save button (posts to existing `update_site_setting` endpoint)

- **`templates/officer/create_event.html`**
  - Added yellow "Push Notification Reminder" section with a `send_reminder` toggle
  - `reminder_hours_before` input shown/hidden via JS when toggle is checked

- **`templates/officer/edit_event.html`**
  - Same reminder section as create, with state restored from existing event
  - Shows confirmation note with timestamp if reminder was already sent

### Models
- **`src/models/events.py`** — added `EventReminderLog` (one per reminder slot dispatch) and `EventReminderRecipient` (one per user per dispatch)

### Views & URLs
- **`src/view/admin_v2.py`** — added `event_reminder_logs` (list) and `event_reminder_log_detail` (per-dispatch breakdown)
- **`src/urls.py`** — `/admin-v2/event-reminder-logs/` and `/admin-v2/event-reminder-logs/<id>/`

### Templates
- **`templates/admin_v2/event_reminder_logs.html`** — list page matching email logs style; shows pending events with unfired reminders at top, dispatched log entries below
- **`templates/admin_v2/event_reminder_log_detail.html`** — per-dispatch detail: summary stats (eligible / subscribed / dispatched / opted out) + full recipient table split into Dispatched and Skipped
- **`templates/admin_v2/dashboard.html`** — "Event Reminder Logs" quick link added to Push card

### Tasks
- **`src/tasks.py`** — added `send_event_reminder_pushes` shared task
  - Runs every 15 minutes (registered in Beat via `setup_celery_schedules`)
  - Checks `push_notifications_enabled` and `push_events` feature flags
  - Checks `event_reminders_enabled` SiteSetting
  - Scans upcoming events (within 7 days) where reminder is due and not yet sent
  - Filters users by event visibility, active push subscription, and `push_events` user preference
  - Marks `reminder_sent_at` after dispatching

### Celery Schedule
- **`src/management/commands/setup_celery_schedules.py`**
  - Added `Send event reminder push notifications` — runs `tasks.send_event_reminder_pushes` every 15 minutes

---

## Deployment Notes

1. Run migration: `python manage.py migrate`
2. Register the new Beat schedule: `python manage.py setup_celery_schedules`
3. Restart Celery Beat to pick up the new task
4. Visit Admin v2 → Push Notifications card to verify the Event Reminder Settings appear
