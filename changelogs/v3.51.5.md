# v3.51.5 — 10-21-26

**Committed:** *not yet*.
**Deployed:** *not yet*.
**Migrations:** none. **`pip install -r requirements.txt`**, then restart Daphne
and `parliament-worker`.
**Applies after v3.51.4.**

From the 10-21-26 auto-run. `pip-audit` reports 9 advisories against Pillow
12.3.0, all fixed in **13.0.0** (released 10-16-26): out-of-bounds reads and
uninitialised memory in the TIFF decoder, a GIF decompression-bomb DoS, a PPM
zero-width crash in `ImageMorph`, unbounded recursion appending to a PDF, and
EPS rendering past the bomb limit.

**How exposed Parliament is:** limited. Pillow is only used through Django's
`ImageField` (profile pictures, landing-page images, bug-report screenshots),
which runs `Image.open()` + `verify()` on upload and doesn't decode pixels,
re-save, morph or append. Profile pictures are limited to JPEG/PNG/WebP; the
bug-report `screenshot` field has no format list, so any signed-in member can
upload a TIFF or GIF there. Upgrading is cheaper than proving each advisory
unreachable.

- `requirements.txt`: `pillow==12.3.0` → `pillow==13.0.0`. Pillow 13 needs
  Python ≥ 3.11 (prod is 3.12). `pip check` is clean.
- Full suite on PostgreSQL 16 with Pillow 13: 3,553 run, no new failures.
