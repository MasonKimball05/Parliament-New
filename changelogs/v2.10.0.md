### Lyrics Update Management Command

Enhanced the `update_song_lyrics` management command with new options:

```bash
# Preview changes without saving
python manage.py update_song_lyrics --dry-run

# Force overwrite existing lyrics
python manage.py update_song_lyrics --force
```

**Features:**
- Title alias support for database titles that don't exactly match songbook titles
- Partial title matching for flexible song identification
- Skip songs that already have lyrics (unless --force is used)
- Clear summary of updated, skipped, and not-found songs

- `src/management/commands/update_song_lyrics.py` - Complete rewrite with clean lyrics

## Bug Fixes

### Pledge Initiation Data Loss

**Issue:** Service hours, attendance records, Kai reports, and other data was being CASCADE deleted when initiating pledges.

**Root Cause:** The old initiation logic deleted the pledge user record before creating the new member record, triggering CASCADE deletes on all related tables.

**Solution:**
- Added `transaction.atomic()` for all-or-nothing operations
- Changed approach from DELETE to INSERT/UPDATE/DELETE sequence
- Added verification step before deletion to check for remaining FK references
- All FK updates logged for audit trail

### Pledge Initiation FK Constraint Errors

**Issue:** Pledge initiation failing with foreign key constraint violations, preventing completion.

**Root Cause:** Multiple issues:
1. Incorrect column names in FK reference list
2. Missing FK references for newer tables
3. Unique constraint conflicts (username, email) during user_id migration

**Solution:**

**Fixed 4 Incorrect FK Column Names:**

| Table | Wrong Column | Correct Column |
|-------|--------------|----------------|
| `src_servicememberexpectation` | `user_id` | `member_id` |
| `src_servicehourssubmission` | `user_id` | `submitted_by_id` |
| `src_servicehoursadjustment` | `user_id` | `member_id` |
| `src_servicehoursadjustment` | `created_by_id` | `adjusted_by_id` |
| `src_announcementemaillog` | `sent_by_id` | `initiated_by_id` |

**Added 12 Missing FK References:**

| Table | Column |
|-------|--------|
| `src_serviceperiod` | `created_by_id` |
| `src_serviceformfield` | `created_by_id` |
| `src_slatingapplication` | `reviewer_id` |
| `src_slatinginterview` | `destroyed_by_id` |
| `src_slatingperiod` | `created_by_id` |
| `src_slatingperiod` | `admin_transferred_from_id` |
| `src_slate` | `created_by_id` |
| `src_slate` | `approved_by_id` |
| `src_kaiformfield` | `created_by_id` |
| `src_notificationschedule` | `created_by_id` |
| `src_committee` | `admin_id` |
