# v2.21.0 — Member Directory Enhancements

**Status:** Code-complete, not yet deployed
**Date:** 05-29-2026

---

## Summary

Client-side filter pills and sort for the member directory. No server round-trips for type filtering — pills show/hide cards by `data-type` entirely in JS. Sort (A→Z, Z→A, Roll #) triggers a page reload with `?sort=` to keep it simple and SSR-friendly.

---

## New Features

### Filter Pills
- Row of pill buttons above the card grid: All, Officers, Chairs, Members, Pledges, Advisors, Alumni
- Clicking a pill hides all cards that don't match `data-type`; clicking All restores them
- Pills only render if that group is non-empty (using `{% if officers %}` guards)
- Alumni pill only appears when `?show_alumni=1` is active
- Active pill is highlighted indigo; inactive pills are gray with indigo hover

### Sort Dropdown
- Replaces (or sits alongside) existing search — A→Z / Z→A / Roll #
- Sort is applied server-side; dropdown change fires `window.location.href` redirect with `?sort=` param
- `sort` and `filter_type` are now in the view context so the template can reflect current state

### data-type Attributes
- All six card groups now carry `data-type="officer|chair|member|pledge|advisor|alumni"` on each card div, enabling client-side JS to filter without DOM traversal heuristics

### Tests (`src/test_pillar3.py`)
- Auth requirement for directory + export views
- Member grouping (officer/chair/member/pledge/advisor each in correct context key, alumni excluded by default)
- Alumni toggle (`?show_alumni=1`)
- Sort: name asc, name desc, roll # ascending, unknown sort value fallback
- `filter_type` context key passed through for all filter values
- Export defaults (CSV, header present, member name present)
- Export form submission (alumni include/exclude, column opt-in/opt-out, TXT format, XLSX format, XLSX fallback to CSV without openpyxl)

## Deployment Steps

1. `git pull origin main`
2. `python manage.py collectstatic --noinput`
3. Restart gunicorn: `systemctl restart parliament`
4. **Purge Cloudflare cache** — directory.html and its JS/CSS are static assets that Cloudflare caches aggressively

No new migrations. No new dependencies.
