The app gets the rest of a committee vote's path to the floor (making it a
chapter vote), the slating chair's election setup and slate builder, the C&B

helpers. Moving that code turned up website bugs, fixed below.

---

## The app: a committee vote becomes a chapter vote

A chair can make a closed committee vote into a chapter vote from the vote's
result or the committee's vote list. The form has the website's fields: the
title, description, when it opens, the voting mode and threshold, abstain, an
anonymous vote, and whether to show the committee's result. The chair can also
remove a chapter vote created by mistake. Both use the website's code, now
shared helpers in `src/committee_management.py`
(`committees/<code>/votes/<id>/chapter-vote/` and `.../chapter-vote/delete/`).

## The app: election setup

Slating chairs and the period's managers can set up an election from their
phone (`src/mobile/views_slating_setup.py`):

- the period's settings, schedule, committee, and its next stage
- positions: add, edit, reorder with up and down buttons, deactivate or
  reactivate, and copy the default positions
- transferring the slating committee's admin

Site admins can also create a new period, set its manager, delete a period,
and hard-delete a position. Opening voting stays on the chair's Run the vote
screen. The application form builder stays on the website.

## The app: the slate builder

The chair builds the slate in the app (`src/mobile/views_slating_slate.py`):
pick a candidate for each position from the eligible applicants (best fit
first, by their ranked choices), preview, approve, copy, and add or remove
write-ins. While voting is open they can edit the approved slate, and record
in-person results. Voting members can see the approved slate once voting
opens.

## Website fixes found along the way

- **Transfer admin never worked.** The member picker sent a blank value, so
  every transfer failed with "Please select a new admin".
- **Copying a slate broke the builder.** A copy is a second draft, and the
  builder and "approve the draft" then failed with a server error. Both now use
  the newest draft, so the builder opens on the copy.
- **A copy dropped runoffs and write-ins.** Copying a slate with a runoff failed;
  write-ins were copied without their member. Both are now copied.
- **Removing a write-in from a draft slate failed** with a server error, and
  the slate's candidate list failed on any slate with a write-in.
- **An incomplete "Edit approved slate" replacement emptied the position.** It
  removed the current candidate before rejecting the choice. The choice is now
  checked first.
- **Saving a position cleared what its form doesn't show.** The edit form only
  has the title, description, GPA and abstain, so every save cleared the
  position's linked role, "requires prior experience" and eligibility lists
  (including the roles "+ Default Positions" links). Those are now kept.
- **A resolution's author couldn't load a section to amend.** The amendment
  editor's section text was refused to authors who weren't the C&B chair or an
  editor, although authors may amend their own resolutions. It now loads for
  them, on the documents members can already read.
- **Abstain couldn't be turned off.** An unticked box sent nothing, which the
  server read as on. The form now sends "off" when it's unticked.

## The app: the resolution builder

Writing a Constitution & Bylaws resolution works in the app
(`src/mobile/views_cnb_resolutions.py`): create and edit it, amend a section
(pick the article and section, see its current text, enter the new text, or
remove the section), propose structure changes (a new article or section, or a
rename), move it through its statuses, and add or remove collaborators. The
same people can do it as on the website: the C&B chair, the author and
collaborators, with the same status locks. An edit someone else saved in the
meantime shows both versions instead of overwriting theirs. Print and the
document preview open the website.

## The app: export the activity logs

Activity Logs has an Export CSV button. It's the website's file for the same
filters, redaction, row limit and "exported" log entry (one shared
`activity_logs_csv`, `officer/activity-logs/export/`), opened in the share
sheet to save to Files or send.
