## Changes

### EXEC Committee Chair Permissions

All members of the EXEC committee now automatically have chair-level permissions without needing to be explicitly listed as chairs.

- **Change**: Updated `is_chair()` method in Committee model to grant chair permissions to all EXEC committee members
- **Benefit**: Simplifies EXEC committee management - no need to add every officer as a chair
- **Scope**: Only affects the EXEC committee (code='EXEC'), not other committees with `is_exec_board=True`

**Files Changed:**
- `src/models.py` - Updated `is_chair()` method

```python
def is_chair(self, user):
    # For EXEC committee specifically, all members have chair permissions
    if self.code == 'EXEC' and self.members.filter(pk=user.pk).exists():
        return True
    return self.chairs.filter(pk=user.pk).exists()
```

## Bug Fixes

### Profile Picture Remove Button Not Working

- **Issue**: Clicking "Remove" on profile picture showed "No file selected" error instead of removing the picture
- **Cause**: Same issue as service hours approval - when JavaScript handles the form, the submit button's `name/value` wasn't being included in the POST data
- **Fix**: Added hidden input field for the action value, set via onclick before form submission
- **Files Changed**:
  - `templates/profile.html` - Added hidden input and onclick handler
  - `src/view/profile_view.py` - Updated to check `action == 'remove'`

```html
<!-- Added hidden input -->
<input type="hidden" name="action" id="profile-picture-action" value="">

<!-- Button onclick sets the value -->
onclick="if(confirm('Remove your profile picture?')) {
    document.getElementById('profile-picture-action').value = 'remove';
    return true;
} return false;"
```

### Announcements Page - Hyperlinks Overflowing on Mobile

- **Issue**: Long URLs in announcement content would extend beyond the container on mobile devices, causing horizontal scrolling
- **Cause**: No word-breaking rules applied to the content container
- **Fix**: Added `overflow-hidden`, `break-words`, and `overflow-wrap: anywhere` to properly wrap long URLs
- **Files Changed**: `templates/announcements.html`

```html
<!-- Before -->
<div class="prose max-w-none mb-4">
    <p class="text-gray-700 ... whitespace-pre-wrap">{{ announcement.content|linkify }}</p>
</div>

<!-- After -->
<div class="prose max-w-none mb-4 overflow-hidden">
    <p class="text-gray-700 ... whitespace-pre-wrap break-words" style="overflow-wrap: anywhere;">
        {{ announcement.content|linkify }}
    </p>
</div>
```

### Directory Page - Export Dropdown Off-Screen on Mobile

- **Issue**: Clicking the "Export" button on mobile caused the dropdown menu to appear off the right edge of the screen
- **Cause**: Dropdown was positioned with `right-0` which aligned it to the right of its container, extending past viewport on narrow screens
- **Fix**: Changed positioning to `left-0 sm:left-auto sm:right-0` - aligns left on mobile, right on larger screens
- **Files Changed**: `templates/directory.html`

```html
<!-- Before -->
<div id="exportMenu" class="hidden absolute right-0 mt-2 ...">

<!-- After -->
<div id="exportMenu" class="hidden absolute left-0 sm:left-auto sm:right-0 mt-2 ...">
```
