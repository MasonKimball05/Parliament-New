**Release Date:** June 7, 2026

**Deployment Status:** ✅ Deployed

**Type:** Performance / Maintenance

---

## Overview

Three independent improvements in one session:

1. **`update_fields` sweep** — every view-layer `.save()` call that wrote specific fields now uses `update_fields` to scope the DB `UPDATE` to only those columns. Reduces write amplification on high-frequency paths.
2. **Pre-existing test fixes** — 9 failing tests corrected; all 57 tests now pass.
3. **Component CSS system** — `btn-*`, `badge-*`, `card`, and `form-input` component classes added via `@layer components`. Eight high-traffic templates updated to use them.

### Test Fixes (`src/test_comprehensive.py`, `src/test_edge_cases.py`)

### Bug Fix — `preferred_name` NOT NULL violation (`src/view/profile_view.py`)

When a user cleared their preferred name via the profile form, the view set `user.preferred_name = None`. The `preferred_name` field is `blank=True` but not `null=True`, so this caused a `psycopg2.errors.NotNullViolation` at the DB level. Fixed to store `''` instead of `None`.

### Component CSS System (`static/css/tailwind-input.css`, 8 templates)

A `@layer components` block was added to `tailwind-input.css` defining reusable component classes. These replace the long inline Tailwind class strings that had grown inconsistent across templates over time.

**Classes defined:**

```css
/* Buttons */
.btn-primary    — blue filled (px-4 py-2 text-sm)
.btn-secondary  — gray outlined
.btn-danger     — red filled
.btn-ghost      — borderless text button
.btn-sm         — size modifier (px-3 py-1.5 text-xs)
.btn-lg         — size modifier (px-6 py-3 text-base)

/* Badges */
.badge          — neutral gray pill
.badge-green    — green status
.badge-red      — red status
.badge-yellow   — yellow/pending status
.badge-blue     — primary blue
.badge-purple   — purple/officer

/* Layout */
.card           — white rounded-xl shadow-sm with border
.form-input     — standard text input (defined, not yet rolled out)
```

**Templates updated** (buttons, badges, and cards replaced):
- `templates/vote.html`
- `templates/passed_legislation.html`
- `templates/directory.html`
- `templates/announcements.html`
- `templates/profile.html`
- `templates/preferences.html`
- `templates/home_modern.html`
- `templates/calendar.html`

**Not touched:** Admin templates, tab navigation buttons (JS-managed active state), buttons inside `<script>` template literals, and templates not in this pass (can be updated incrementally when next touched).

**For future development:** New buttons should use `<button class="btn-primary">` rather than inline class strings. The full list of available classes is documented in `tailwind-input.css`.
