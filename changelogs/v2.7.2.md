## Overview

This release improves the chat system with better timestamps, feature flag control for polling, and fixes bug report email notifications for Brevo.

---

## Key Features

### 1. Chat Message Timestamps Include Date

Chat messages now display the date alongside the time for better context.

**Before:** `4:30 PM`
**After:** `Mar 3, 4:30 PM`

**Changes:**
- Server-side Django template updated to use `M j, g:i A` format
- Client-side JavaScript updated to include month and day for dynamically loaded messages

---

### 2. Chat Feature Flag with Polling Control

Added a proper feature flag (`chats`) to enable/disable the entire chat system, including automatic polling.

**How It Works:**
1. Feature flag `chats` controls all chat functionality
2. When disabled:
   - Chat pages return 403 Forbidden
   - JavaScript polling does not start
   - Status shows "⊘ Chat feature is disabled"
3. If disabled mid-session:
   - Polling detects 403 response and stops automatically
   - Status updates to "⊘ Chat feature has been disabled"

**Admin Control:**
- Navigate to Admin v2 → Feature Flags
- Toggle "Chat System" (`chats`) to enable/disable

**Technical Details:**
- Fixed mismatch between seed file (`chat_system`) and decorators (`chats`)
- Added `chat_enabled` context variable to template
- JavaScript checks `CHAT_ENABLED` before starting poll intervals
- Graceful 403 error handling stops polling without console spam

## Bug Fixes

### Bug Report Email Notifications Not Sending

**Issue:** Bug report email notifications were not being sent on the production server using Brevo.

**Cause:** The `send_bug_report_notification()` function checked for `EMAIL_HOST_USER`, which is empty when using Brevo (Anymail). Brevo uses `ANYMAIL.BREVO_API_KEY` instead.

**Fix:** Updated the email configuration check to look for:
- SMTP credentials (`EMAIL_HOST_USER`)
- Brevo credentials (`ANYMAIL.BREVO_API_KEY`)
- Console backend (for development)

```python
# Before (broken for Brevo)
if not getattr(settings, 'EMAIL_HOST_USER', None):
    return  # Skip silently

# After (works with SMTP and Brevo)
has_smtp = bool(getattr(settings, 'EMAIL_HOST_USER', ''))
has_brevo = bool(getattr(settings, 'ANYMAIL', {}).get('BREVO_API_KEY', ''))
if not has_smtp and not has_brevo and not is_console_backend:
    return  # Skip silently
```

## Deployment Steps

1. **Pull latest code**
   ```bash
   git pull origin main
   ```

2. **Restart application**
   ```bash
   sudo systemctl restart gunicorn
   ```

3. **(Optional) Re-seed feature flags** if `chats` flag doesn't exist:
   ```bash
   python manage.py seed_feature_flags
   ```
