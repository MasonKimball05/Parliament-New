## 🟢 Mobile app: Constitution & Bylaws reader (Mason, 10-29-26)

- `src/mobile/views_cnb.py`:
  - `cnb/` — every document members can see (`GoverningDocument.enabled()`,
    so the per-document flags apply), by article and section, with the
    Document tab's suspension, partial-suspension and amendment-protection
    notes.
  - Each section lists its cross-references that resolve (`find_references` +
    `Structure.exists`, as `cnb_linked`), with offsets in UTF-16 code units so
    the app can slice them directly.
  - `cnb/resolutions/` and `cnb/resolutions/<id>/` — the Resolutions tab and a
    read-only resolution: clauses, body, notes and amendments. `can_edit` uses
    `_can_edit_resolution`.
- Writing, editing, managing, section history and the PDF stay on the website;
  the app links to them.
- `src/mobile/deeplinks.py` — `/constitution-bylaws/` → `cnb` and
  `/resolutions/<id>/` → `resolution`. Older app versions fall back to the web
  view for screens they don't know.
- Tests: `src/tests/mobile/test_cnb.py`.
