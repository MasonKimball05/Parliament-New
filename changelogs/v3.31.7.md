## 🟠 Quiz grading was undiscoverable from the two pages a VPE actually opens

Mason: *"On this page I can see the tasks in progress, can you make it for
quizzes I can click on it and it shows the work they did and the answers so
they can be 'graded'? `committee/EDUCATION/education/pledge/2/` Also I don't
see a way to view all the test responses from the dashboard. Can you make it
more apparent how to view this if it's there already?"*

### What was already there

The grading UI itself was fully built on `education_quiz_submissions`
(`quiz_submissions.html`) — per-question Right/Wrong/Clear marking, score
entry, Mark Passed/Mark Incomplete — all working. The problem was purely
discoverability: the page was linked from nowhere except a "Breakdown"
link buried behind row-hover on the dashboard, and *that* page's own
"← Submissions" link, worded and styled as an exit rather than an entrance.
Neither the main dashboard's plain view nor the per-pledge detail page (the
page Mason actually opens to check on one pledge) linked to it at all.

### The fix

- **`templates/committee/education_pledge_detail.html`** — each quiz-type
  task row now shows a "View answers →" link next to its Required badge,
  deep-linking to `education_quiz_submissions` with a `#pledge-<pk>`
  fragment so it lands directly on *that* pledge's own card rather than the
  top of a page listing every pledge.
- **`templates/committee/education.html`** — every quiz-type task row on the
  main dashboard now shows a persistent "📝 View submissions" link in the
  sticky title cell, next to the task title — not hidden behind row-hover
  like Duplicate/Questions/Breakdown/Delete, and not gated on `is_chair`
  (viewing is read-only; grading itself is still chair-gated on the
  submissions page). Hover-hidden links don't solve a discoverability
  complaint, so this one is deliberately always visible.
- **`templates/committee/quiz_submissions.html`** — each pledge's card now
  carries `id="pledge-{{ row.pledge.pk }}"`, plus a `:target` CSS rule that
  outlines whichever card a `#pledge-<pk>` link landed on, so the two new
  links actually land somewhere useful instead of just scrolling to the top
  of the page.

### Tests

New `src/tests/education/test_quiz_grading_visibility.py` (11 tests):
the dashboard link appears only for quiz tasks and is visible to a
non-chair officer but still 404s for a plain member denied the page; the
pledge-detail link points at the correct pledge's own anchor and not
another pledge's; a page with only a non-quiz task shows no answers link at
all; and every pledge on the submissions page gets its own anchor with no
inline event handlers introduced.
