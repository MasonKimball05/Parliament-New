# v2.8.4 - QOL/UX Improvements, Attendance Dashboard & Excuse Redesign

**Release Date:** March 26, 2026

**Deployment Status:** Deployed

## Overview

Major UX improvements including a new attendance dashboard system, pagination, modal accessibility, reusable components, and a complete redesign of the excuse request pages for both members and officers.

---

## Attendance Dashboard

New comprehensive attendance tracking and analytics system for both officers and members.

### Officer Dashboard (`/officers/attendance/dashboard/`)

Full chapter-wide attendance analytics with:

- **Chapter Statistics** - Overall attendance rate, event counts, present/absent/excused breakdowns
- **Monthly Trends** - Visual progress bars showing attendance rate by month
- **Event Series Analysis** - Attendance rates for recurring events (e.g., "Chapter Meeting" series)
- **Recent Events Table** - Quick view of attendance for the last 15 events
- **Member Statistics** - All members ranked by attendance rate with drill-down details
- **Date Range Filter** - View stats for 30/60/90/180/365 days or all time

**URLs:**
- `/officers/attendance/dashboard/` - Main officer dashboard
- `/officers/attendance/member/<user_id>/` - Individual member detail view

### Member Dashboard (`/my-attendance/`)

Personal attendance tracking for individual members:

- **Personal Stats** - Your attendance rate compared to chapter average
- **Rate Comparison** - See if you're above or below average with color-coded badges
- **Event Series Breakdown** - Your attendance for recurring event types
- **Attendance History** - Scrollable list of all events with your status
- **Tips Section** - Helpful reminders about excuses and attendance

**Files Created:**
- `src/view/officer/attendance_dashboard.py` - Officer dashboard and member detail views
- `templates/officer/attendance_dashboard.html` - Officer dashboard UI
- `templates/officer/member_attendance_detail.html` - Member detail view for officers
- `templates/my_attendance.html` - Member personal dashboard

**Files Modified:**
- `src/view/submit_excuse.py` - Added `my_attendance` view
- `src/urls.py` - Added new URL routes

### Modal Accessibility

Improved modal dialogs throughout the application with proper accessibility features.

- **Escape key** closes modals
- **Focus trapping** keeps focus within modal when open
- **ARIA attributes** for screen readers
- **Click outside** to close

**Files Changed:**
- `templates/base.html` - Added `ParliamentModal` JavaScript utility and `confirmAction()` helper

```javascript
// Usage example
ParliamentModal.open('myModal');
ParliamentModal.close('myModal');
confirmAction('deleteModal', '/delete/123/', { message: 'Delete this item?' });
```

## Excuse Page Redesign

Complete UI overhaul for both member and officer excuse pages.

### Member Excuse Page (`/excuses/`)

**Before:** Table-based layout for available events, separate card layout for history. Inconsistent visual hierarchy.

**After:**
- **Status summary cards** at top showing pending/approved/denied/total counts
- **Card-based layout** for available events with clear deadline highlighting
- **Unified design** for submitted requests with color-coded status bars
- **Better mobile responsiveness** with proper stacking and touch targets
- **Cleaner review info display** with reviewer avatar and quoted notes

**Files Changed:**
- `templates/my_excuses.html` - Complete rewrite
- `src/view/submit_excuse.py` - Added excuse counts to context

---

### Officer Review Page (`/officers/excuses/`)

**Before:** Tab-based interface requiring multiple clicks to switch between events. Confusing with many events.

**After:**
- **All events visible at once** grouped in expandable cards
- **Global statistics** at top showing pending counts across all events
- **Status filter bar** to quickly filter by pending/approved/denied
- **Inline approve/deny buttons** for quick actions
- **Per-event pending badges** with pulse animation for attention
- **Cleaner modal** for adding review notes
- **Better mobile layout** with responsive flex containers

**Files Changed:**
- `templates/officer/review_excuses.html` - Complete rewrite
- `src/view/officer/event_attendance.py` - Restructured data for grouped display
