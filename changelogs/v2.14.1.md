# v2.14.1 - Archive Detail Pages

**Release Date:** May 12, 2026

**Deployment Status:** Not yet deployed

**Type:** Cleanup

---

## Overview

Several standalone "detail pages" built as supplements to the Constitution/Bylaws and Roberts Rules pages have been archived. These pages were no longer needed and added maintenance surface area with no active use.

---

## What Changed

### Pages Archived

The following pages have been removed from routing and moved to archive folders:

| Page | URL |
|---|---|
| Passed Resolutions | `/constitution-bylaws/passed-resolutions/` |
| Officer Duties | `/constitution-bylaws/officer-duties/` |
| Committee Details | `/constitution-bylaws/committees/` |
| Kai Procedures | `/constitution-bylaws/kai-procedures/` |
| Slating & Elections | `/constitution-bylaws/slating-elections/` |
| Chapter Advisors | `/constitution-bylaws/advisors/` |
| Academic Standards | `/constitution-bylaws/academic-standards/` |

View files moved to `src/view/archive/`. Template files moved to `templates/archive/`. Nothing was deleted.

### Links Removed

**`constitution_bylaws.html`**:
- Entire "Detail Pages" sidebar nav section removed
- "Passed Resolutions" callout block removed from main content
- Inline callout blocks for Officer Duties, Committee Details, Slating & Elections, Academic Standards (×2), and Advisors removed
- Kai Procedures link removed from the Self-Governance reference block (PDF links kept)
- Inline "See Academic Standards Guide" link removed from membership standards list

**`roberts_rules.html`**:
- "Committee Details page" link removed from the Standing Committees section (surrounding text kept)

**`officer/manage_resolutions.html`**:
- "View Public Page →" link to Passed Resolutions removed from the officer tip banner

### URLs Removed

7 URL patterns and their imports removed from `src/urls.py`. The `view_reference_document` route (PDF viewer) is unaffected.

---

## Breaking Changes

Any bookmarked or externally linked URLs to the archived pages will 404. These were internal-only pages with no external presence.
