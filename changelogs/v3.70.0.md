## 🟢 Mobile app: Songbook and Quote Book (Mason, 10-30-26)

`src/mobile/views_songbook.py`.

- **Songbook** (`songbook/`): every active song with its category, first line
  and lyrics. The list comes in one response, and the app searches and filters
  it on the phone.
  - `songbook/songs/<id>/` is one song. `songbook/songs/<id>/audio/` serves its
    recording with the sign-in token, and the app keeps a copy on the phone.
  - `songbook/pdf/<sheet_music|songbook>/` serves the printed songbook PDFs
    when they are on disk.
  - Same gate as the web pages: no page toggle, the pledge restriction applies.
  - Adding and editing songs stays on the website (`can_manage` shows the link).
  - `song_audio_path` and `exportable_media_url` were moved out of
    `serve_song_audio` / `songbook_list` so both sides use one copy.
- **Quote Book** (`quote-book/`, behind `PageToggle('quote_book')`): one chapter
  per member, built as `quote_book` builds it.
  - Add a quote, either as a POST to `quote-book/` or from
    `quote-book/members/`, which lists everyone not removed.
  - Flag a quote (or delete it, for your own quote about yourself) and restore
    one, with the same `Quote.can_be_*_by` rules and activity log entries as
    the web.
  - `quote-book/flagged/` is scoped like `review_flagged_quotes`: officers see
    every flagged quote, everyone else only the ones they flagged or that are
    about them.
- `me/` `pages` gains `quote_book`, so the app hides the row when the page is
  off.
- Tests: `src/tests/mobile/test_songbook_quotes.py`.
