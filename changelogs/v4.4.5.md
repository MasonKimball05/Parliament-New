## Shortened addresses go somewhere

Deleting the end of an address used to land on "not found" for a handful of
folders that have pages under them but no page of their own. Each now goes to
the page that folder is about (a temporary redirect):

| Address | Goes to |
|---|---|
| `/committee/` | Committees |
| `/legislation/` | Passed legislation |
| `/meetings/` | Agendas |
| `/chat/` | Chats |
| `/songbook/song/` | Songbook |
| `/guide/article/` | The Guide |
| `/account/`, `/accounts/` | Preferences |
| `/cnb/resolutions/` | The C&B resolutions tab |

Admin v2's site map stops flagging them, and committees still sit under
Committees there rather than under the `/committee/` redirect.
