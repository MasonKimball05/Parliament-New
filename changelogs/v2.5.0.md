# Parliament v2.5.0 - Chapter Minutes, Announcements & Document Viewer

**Release Date:** January 28, 2026
**Status:** ✅ Deployed to Production
**Type:** Minor Release - Major Feature Additions

---

## Overview

This release introduces the Chapter Minutes system — a full-featured meeting minutes editor with embedded motions, attendance tracking, PDF generation, and publishing. It also adds an Announcements system with scheduling and email tracking, a unified Document Viewer supporting DOCX/TXT/PDF/image preview, enhanced officer tools for event and resolution management, and encrypted IP address storage for login history.

1. **Chapter Minutes System** - Create, edit, publish, and export chapter meeting minutes with inline motions, votes, section headers, attendance snapshots, and PDF generation
2. **Announcements System** - Officer-managed announcements with scheduling, member targeting, email tracking, and view statistics
3. **Document Viewer** - Unified in-app document viewer for legislation, chapter documents, committee documents, and reference documents with DOCX-to-HTML conversion and text file preview
4. **Officer Dashboard Enhancements** - Event management, resolution management, report uploads, activity logs, and archived events
5. **IP Address Encryption** - Login history IP addresses are now encrypted at rest using EncryptedCharField
6. **Committee Voting Timer** - Optional `voting_ends_at` field for committee legislation votes

## Key Features

### 1. Chapter Minutes System

#### Overview
A complete meeting minutes system allowing officers to create, edit, and publish chapter meeting minutes. The editor uses a single-textarea architecture with inline markers for motions, section headers, and section enders, providing a clean editing experience while preserving structured data for PDF export.

#### Minutes List & Creation
- **Minutes List** (`/officers/minutes/`) — View all draft and published minutes sorted by date
- **Create Minutes** — Set title, date, start time, and optionally link to an existing event
- **Status Tracking** — Draft → Published workflow with visual status badges (yellow for Draft, green for Published, orange for Edited)

#### Editor Features

**Single Textarea Editor**
- All minutes content lives in one textarea with inline markers for structured elements
- Marker protection prevents accidental editing/deletion of motion and section markers
- Auto-resize textarea grows with content
- Keyboard-friendly workflow

**Motion Tracking**
- Add motions inline at cursor position via "Add Motion at Cursor" button
- Comprehensive motion form with:
  - Motion type presets (Approve Previous Minutes, Adjourn, Table, Call the Question, etc.)
  - Author selection from member list or free text
  - Second tracking (received second, seconded by)
  - Voting method (voice, show of hands, roll call, ballot, unanimous consent, standing)
  - Vote counts (for, against, abstain)
  - Result (passed, failed, tabled, withdrawn, referred, no vote)
  - Optional caucus tracking (moderated/unmoderated, duration, speaker time)
  - Context notes
- Motion markers displayed as `──── ⚖ Motion Text ────` in the textarea
- Motion cards shown below the textarea for quick editing/deletion
- Edit and delete existing motions

**Section Headers & Enders**
- Add custom section headers at cursor position (e.g., "Officer Reports", "Old Business")
- Quick presets for common sections: Officer Reports, Old Business, New Business, Committee Reports, Announcements, Good of the Order
- Section end markers to close a section
- Paired header/ender markers create boxed sections in the PDF output
- Section markers displayed as `──── § Title ────` and `──── §/ ────`
- Cards below textarea show sections in order of appearance

**Attendance Tracking**
- Collapsible attendance section in the editor
- Pull attendance from linked event or manually manage
- Mark members as Present, Absent, or Excused
- Attendance count display (present / total)
- Attendance snapshot saved with the minutes

**Adjournment**
- End time input in the header bar with "set to now" button
- Prominent "Adjourn Meeting" button at the bottom of the editor near the Publish section
- Sets end time to current time with visual confirmation

**Auto-Save & Manual Save**
- Manual "Save" button with visual feedback
- Quiet save after motion/section add/edit/delete operations

#### PDF Generation
- Professional PDF output using ReportLab
- Includes:
  - Title, date, called to order / adjourned times
  - Full text content with proper paragraph formatting
  - Motion blocks with blue styling showing all motion details
  - Section headers with purple styling
  - Boxed sections (header + ender pairs) with purple left border and light purple background
  - Attendance table with present/absent/excused status
  - Edit history section (amber styling) when published minutes have been edited
- Preview PDF in browser or download as file

#### Publishing
- Publish minutes as a PDF to the Chapter Documents page
- Visibility options: All Chapter Members or Officers Only
- Published minutes get a green "Published" badge
- Editing published minutes:
  - Warning banner displayed
  - Edit reason prompted and recorded
  - Edit history tracked (timestamp, editor, reason)
  - Published PDF automatically regenerated on save

#### Deletion
- Admin-only delete capability
- Confirmation required
- Deletes associated sections, motions, and published documents

#### Routes
```
GET  /officers/minutes/                      — List all minutes
POST /officers/minutes/create/               — Create new minutes
GET  /officers/minutes/<id>/edit/            — Edit minutes
POST /officers/minutes/<id>/save/            — Save minutes data (AJAX/JSON)
POST /officers/minutes/<id>/save-attendance/ — Save attendance (AJAX/JSON)
POST /officers/minutes/<id>/publish/         — Publish to chapter documents
GET  /officers/minutes/<id>/download-pdf/    — Download PDF
POST /officers/minutes/<id>/delete/          — Delete minutes
```

### 2. Announcements System

#### Overview
A system for officers to create, manage, and schedule announcements with member targeting, email tracking pixel support, and engagement statistics.

#### Public Features
- **Announcements Page** (`/announcements/`) — View all active announcements
- Date range filtering (Past 7 days, 30 days, 90 days, past year)
- Search by title and content
- Dismissible announcement cards
- View tracking (site vs. email source)

#### Officer Management
- **Manage Announcements** (`/officers/announcements/`) — List all announcements with status
- **Create Announcement** — Title, content, publish date (scheduling), event date, visibility targeting
- **Edit & Delete** — Full CRUD operations
- **Toggle Status** — Enable/disable announcement visibility
- **Statistics** — View per-announcement engagement data (views, dismissals, email opens)

#### Email Tracking
- Transparent tracking pixel endpoint for email open tracking
- Tracks which users viewed the announcement via email vs. site
- No authentication required for tracking pixel (works in email clients)

#### Routes
```
GET      /announcements/                                 — View announcements
GET/POST /officers/announcements/                        — Manage announcements
GET/POST /officers/announcements/create/                 — Create announcement
GET/POST /officers/announcements/<id>/edit/              — Edit announcement
POST     /officers/announcements/<id>/delete/            — Delete announcement
POST     /officers/announcements/<id>/toggle/            — Toggle visibility
GET      /officers/announcements/<id>/stats/             — View statistics
GET      /track/announcement/<id>/user/<user_id>/        — Email tracking pixel
```

### 3. Document Viewer

#### Overview
A unified in-app document viewer that supports multiple file formats. Previously, documents opened in new tabs or required downloads. Now they render inline with a professional viewer UI including back navigation, file type badges, open-in-new-tab, and download buttons.

#### Supported File Types
- **PDF** — Embedded PDF viewer
- **Images** — JPG, JPEG, PNG, GIF, WEBP, BMP, SVG with centered display
- **DOCX** — Converted to HTML via `mammoth` library, rendered in a styled "paper" container with serif typography, table formatting, and dark mode support
- **Text Files** — TXT, MD, CSV, LOG, JSON, XML, HTML, CSS, JS, PY rendered in a monospace `<pre>` block with encoding fallback (UTF-8 → Latin-1) and size truncation (500KB max)
- **Other** — Fallback download prompt

#### View Functions
```
GET /legislation/<id>/document/                  — Legislation document viewer
GET /chapter-documents/view/<id>/                — Chapter document viewer (permission-checked)
GET /committee/<code>/documents/<id>/view/       — Committee document viewer (permission-checked)
GET /legislation/detail/<id>/document/           — Passed legislation document viewer
GET /reference-document/<slug>/                  — Reference document viewer
```

#### Reference Documents
Pre-configured reference document slugs:
- `constitution-bylaws` — Constitution & Bylaws PDF
- `code-of-beta` — Code of Beta PDF
- `kai-binder` — KAI Binder PDF
- `trial-by-chapter` — Trial by Chapter PDF
- `roberts-rules` — Robert's Rules of Order PDF

### 5. IP Address Encryption

Login history IP addresses are now stored using `EncryptedCharField` instead of plain text. This applies to the `LoginHistory` model's `ip_address` field. Multiple migrations (0061–0067) handle the transition and field adjustments.

---

### 6. Committee Voting Timer

Added optional `voting_ends_at` (DateTimeField) to `CommitteeLegislation` model, allowing committee chairs to set a deadline for when voting on legislation should automatically close.

## Database Changes

### New Models

**ChapterMinutes** (Migration 0064)
```
- id, title, date, start_time, end_time
- event (FK → Event), created_by (FK → User)
- status: draft | finalized | published
- attendance_taken, attendance_data (JSON)
- publish_visibility: all_members | officers_only | custom
- published_document (FK → CommitteeDocument)
- edited_after_publish, last_edit_at, last_edit_by (FK), last_edit_reason
- created_at, updated_at
```

**MinutesSection** (Migration 0064, updated 0070, 0071)
```
- id, minutes (FK → ChapterMinutes)
- section_type: text | motion | header | section_end
- order, content, title
- created_at
```

**MinutesMotion** (Migration 0064)
```
- id, section (OneToOne FK → MinutesSection)
- motion_type (custom, approve_prev_minutes, adjourn, table, etc.)
- motion_text, context_notes
- author (FK → User), author_text
- received_second, seconded_by_text
- vote_method: voice | show_of_hands | roll_call | ballot | unanimous_consent | standing
- votes_for, votes_against, votes_abstain
- result: passed | failed | tabled | withdrawn | referred | no_vote
- caucus_held, caucus_duration, caucus_type, speaker_time
```

**Announcement** (pre-existing, enhanced with migrations 0055–0056)
```
- title, content, posted_by, posted_at, publish_at, event_date
- is_active, visible_to (JSON)
```

**UserAnnouncementView** (pre-existing, enhanced with migration 0056)
```
- user, announcement, viewed_at, dismissed
- view_source: site | email
```

### Modified Models

**CommitteeLegislation** (Migration 0060)
- Added `voting_ends_at` (DateTimeField, nullable)

**CommitteeDocument** (Migration 0064)
- Made `committee` field nullable (to support chapter-level documents from minutes publishing)

**LoginHistory** (Migrations 0061–0067)
- Changed `ip_address` from plain CharField to EncryptedCharField

### Migrations Required
```bash
python manage.py migrate
```
Migrations 0060 through 0071 (12 migrations total).

## Deployment Guide

### Step 1: Install New Dependencies
```bash
pip install mammoth reportlab
```
- `mammoth` — DOCX-to-HTML conversion for document viewer
- `reportlab` — PDF generation for chapter minutes

### Step 2: Pull Code Changes
```bash
cd /var/www/Parliament-New
git pull origin main
```

### Step 3: Run Migrations
```bash
source venv/bin/activate
python manage.py migrate
```
This runs migrations 0060–0071 (creates new tables, modifies existing fields).

### Step 4: Collect Static Files
```bash
python manage.py collectstatic --noinput
```

### Step 5: Restart Services
```bash
sudo systemctl restart parliament
```

### Step 6: Verify Deployment
1. Navigate to `/officers/minutes/` — verify minutes list loads
2. Create a test minutes entry and verify the editor works
3. Add a motion, section header, and section ender
4. Test PDF preview and download
5. Navigate to `/announcements/` — verify announcements page loads
6. Test document viewer by opening a chapter document
7. Verify DOCX and TXT files render inline
