# Parliament v2.6.2 - Directory Phone Numbers

**Release Date:** February 17, 2026
**Status:** In Development

---

## New Features

### Optional Phone Number for Directory

Members can now add their phone number to their profile for display in the member directory.

**Changes:**
- Added optional `phone_number` field to user profile
- Phone numbers display in the member directory as clickable links
- Search functionality includes phone numbers
- Users control whether to share their phone number (leave blank to hide)
- Auto-formatting as you type (XXX-XXX-XXXX format)
- Smart paste handling (strips country code, formats automatically)

**User Experience:**
- Navigate to Profile → Account Settings
- Enter phone number in the new "Phone Number" field
- Number auto-formats as you type: `1234567890` → `123-456-7890`
- Phone number appears in the directory with a `tel:` link for easy calling/texting on mobile

**Files Modified:**
- `src/models.py` - Added `phone_number` field to ParliamentUser
- `src/view/profile_view.py` - Handle saving phone number
- `src/templatetags/custom_filters.py` - Added `format_phone` filter
- `templates/profile.html` - Added phone number input with auto-formatting JS
- `templates/directory.html` - Display formatted phone numbers, added to search

**Migration Required:**
```bash
python manage.py makemigrations src --name add_phone_number_field
python manage.py migrate
```
