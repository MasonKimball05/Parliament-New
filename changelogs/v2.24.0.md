# v2.24.0 — Extended Member Profiles & Directory Profile Card

**Status:** Deployed
**Date:** 2026-05-29

---

## Summary

Members now have a richer optional profile and the directory is now interactive. Clicking any member's name or profile picture in the directory opens a popup modal that shows everything they've chosen to fill in — bio, academics, pledge class, big/little brothers, graduation timeline, social handles, current roles, and a full role history. All new fields are optional; the modal degrades gracefully to just contact info if nothing extra has been added.

---

## What Changed

### New Profile Fields on `ParliamentUser`

All fields are optional (blank/null) so existing accounts are unaffected.

| Field | Type | Notes |
|---|---|---|
| `about_me` | TextField | Short bio |
| `major` / `minor` / `concentration` | CharField(100) | Academics |
| `big_brother` | ForeignKey(self) | FK to another member; reverse is `little_brothers` |
| `pledge_class` | CharField(30) | e.g. "Spring 2024" |
| `graduation_year` | PositiveSmallIntegerField | 4-digit year |
| `graduation_semester` | CharField(6) | "Fall" or "Spring" |
| `instagram` / `twitter` / `linkedin` / `snapchat` / `facebook` | CharField | Handle only (no URL) |
| `other_email` | EmailField | Secondary contact email |

### New `RoleHistory` Model

Tracks positions held over time. Separate from the live `roles` M2M, which reflects currently held roles.

```
RoleHistory.role_name      — "President"
RoleHistory.start_semester — "Spring 2026"
RoleHistory.end_semester   — "Fall 2026" (blank = current)
```

### New Endpoint: `GET /directory/<user_id>/card/`

Returns JSON for the profile modal. Authenticated only. Returns 404 for unknown `user_id`. Does not expose sensitive admin flags.

### Directory Profile Card Modal

- Clicking a member's **name** or **avatar** in the directory opens the modal
- Fetches profile data via `fetch()` — shows a spinner while loading, error state on failure
- Sections only render if the member has data: About, Contact, Academics, Chapter info (pledge class, graduation, big/littles), Current Roles, Role History, Socials
- Social handle links open in a new tab with `rel="noopener noreferrer"`
- Keyboard-accessible: `Escape` closes the modal; focus-ring on avatar buttons
- Backdrop click also closes
