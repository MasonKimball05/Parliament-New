## Ideas Under Consideration

### GroupMe Bot Integration for Announcements

**Status:** Researching

Exploring the possibility of using a GroupMe bot to send automated notifications to the chapter's announcements channel instead of SMS text reminders.

**Potential Features:**
- Event reminders sent to GroupMe announcements channel
- New announcement notifications
- Vote reminders ("You have X pending votes")
- Attendance/excuse reminders

**How It Would Work:**
- GroupMe Bot API (dev.groupme.com)
- Simple HTTP POST requests with Bot ID
- One-way messaging (bot sends, doesn't read)
- Messages go to entire channel

**Benefits:**
- No SMS costs
- Centralized notifications in existing GroupMe
- Easy to set up and maintain

**Considerations:**
- Cannot target individual users (channel-wide only)
- One-way communication only
- Need to decide: separate bots per notification type?
- User opt-in/out for triggering notifications when creating events?
- Keep SMS as backup or fully replace?

**Research Needed:**
- GroupMe rate limits
- Best practices for bot message formatting
- Whether to use callbacks for two-way interaction
