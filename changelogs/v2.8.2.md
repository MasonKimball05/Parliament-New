## New Features

### Officer Admin Sync

A new tool for admins to sync admin privileges based on officer roles.

- **Sync Button**: Added "Sync Officer Admins" button to the Manage Members page (admin only)
- **Dynamic Role Configuration**: Roles can be marked with `grants_admin=True` in the database
- **Protected Accounts**: User ID 73 is protected and cannot have admin removed
- **Activity Logging**: All sync operations are logged to ActivityLog

**How it works:**
1. Users with roles that have `grants_admin=True` are automatically made site admins
2. Users who no longer have these roles lose admin privileges (except protected accounts)
3. Default admin-granting roles: President, EVP, VPB (Vice President of Brotherhood)

### Ad-Hoc Committee Expiration & Archiving

Added support for optional expiration dates on ad-hoc committees and archiving functionality.

**Features:**
- Set optional expiration date when marking a committee as ad-hoc
- Expiration date displayed in the Type column of Manage Committees
- Archive/restore committees (archived committees become read-only)
- Archive button in actions column for quick archiving
- Archived status shown with orange badge

**How it works:**
1. When creating or editing an ad-hoc committee, you can set an expiration date
2. Expired ad-hoc committees should be archived (not deleted) to preserve history
3. Archived committees are read-only and can be restored or deleted by admins

**Files Changed:**

## Bug Fixes

### Service Hours Form Showing Duplicate Fields

- **Issue**: The service hours submission form was displaying all fields twice - once from the Django form and again in the custom fields section
- **Cause**: Built-in fields (period, hours, service_date, organization, description, attachment) were being included in the `custom_fields` query after being added to ServiceFormField table
- **Fix**: Added `is_builtin=False` filter to exclude built-in fields from custom fields rendering
- **Files Changed**: `src/view/service_user_dashboard.py` (both `submit_service_hours` and `edit_service_submission` functions)

```python
# Before
custom_fields = ServiceFormField.objects.filter(is_active=True).order_by('section', 'display_order')

# After
custom_fields = ServiceFormField.objects.filter(is_active=True, is_builtin=False).order_by('section', 'display_order')
```

---

### Login History Not Being Recorded

- **Issue**: Login history and security alerts pages were showing blank on production - no logins were being tracked
- **Cause**: Two issues:
  1. App registered as `'src'` instead of `'src.apps.SrcConfig'` in settings, so the `ready()` method wasn't called and signals weren't loaded
  2. `CRYPTOGRAPHY_KEY` missing from `base_settings.py` (required for encrypting IP addresses)
- **Fix**:
  1. Changed `'src'` to `'src.apps.SrcConfig'` in both `settings_postgres.py` and `base_settings.py`
  2. Added `CRYPTOGRAPHY_KEY` to `base_settings.py`
- **Files Changed**:
  - `Parliament/settings_postgres.py`
  - `Parliament/base_settings.py`

---

### Service Hours Approval Button Not Working

- **Issue**: Clicking "Approve" on pending service hour submissions wasn't changing the status - submissions remained pending
- **Cause**: When JavaScript disabled the submit buttons before form submission, some browsers weren't including the button's `name/value` in the POST data
- **Fix**: Added a hidden input field for the action value, which JavaScript sets before disabling buttons
- **Files Changed**: `templates/service_hours/manage_submission.html`

```html
<!-- Added hidden input -->
<input type="hidden" name="action" id="action-input" value="">

<!-- JavaScript now sets this before form submits -->
document.getElementById('action-input').value = action;
```

### New Models

#### ServiceHoursAdjustment
```python
class ServiceHoursAdjustment(models.Model):
    """Manual hour adjustments made by VPP or admins."""
    period = models.ForeignKey(ServicePeriod, on_delete=models.CASCADE, related_name='adjustments')
    member = models.ForeignKey(ParliamentUser, on_delete=models.CASCADE, related_name='service_adjustments')
    hours = models.DecimalField(max_digits=5, decimal_places=2, help_text="Hours to add (positive) or remove (negative)")
    reason = models.TextField(help_text="Required explanation for this adjustment")
    adjusted_by = models.ForeignKey(ParliamentUser, on_delete=models.SET_NULL, null=True, related_name='service_adjustments_made')
    created_at = models.DateTimeField(auto_now_add=True)
```
