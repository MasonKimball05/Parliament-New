## 🟢 Mobile app: Recruitment and Education dashboards (Mason, 10-29-26)

- `src/mobile/views_recruitment.py` — `committees/<code>/recruitment/`: events
  (public only without private access), event detail with sign-ups or RSVPs,
  create / edit / delete events, RSVP and check-in, and the candidate pipeline
  (add, edit, delete, status, notes). Same access helpers as the web
  (`_user_access`, `_can_manage`, `_can_view_private`, `_can_take_attendance`).
  Unlike the web form, editing an event from the app leaves its RSVP reminder
  settings alone, and a manager who can't read private notes can't overwrite them.
- `src/mobile/views_education.py` — `committees/<code>/education/`: pledge
  progress and points, tasks, meetings, absence requests; one pledge's page;
  one task with every pledge's mark and quiz answers; marking tasks and answers
  (grade); attendance, absence review, setting / advancing phases (manage).
  Building tasks, quizzes, meetings, bigs, point adjustments and page access
  stays on the website.
- The web dashboard's numbers moved into shared functions so the app and the
  site can't disagree: `education_overview(committee)` (used by `education_home`)
  and `pledge_progress(committee, pledge)` (used by `education_pledge_detail`).
  No change to either web page.

## 🟢 Committee member permissions (Mason, 10-29-26)

Chairs (and the committee's VP and site admins) can now choose who on the
committee can take minutes, manage documents and manage members, on a new
Member Permissions page (`committee/<code>/member-permissions/`, linked from
the committee page). The flags already lived on `CommitteePermissions`; only
`can_take_minutes` was ever checked and nothing set them.
- Upload, replace, publish and delete a document: chairs, VP, admins, or
  `can_upload_docs` (was chairs / VP only).
- Manage Members: chairs, VP, admins, or `can_manage_members`. It was behind
  `@committee_chair_required`, so its own `can_manage_members` check never let
  anyone else in.
- Take minutes: the committee page now shows Minutes to a designated
  minute-taker (it was in the chairs-only block), and the minutes pages admit
  one who isn't a member (an advisor) — `is_committee_member_or_above` counts
  `can_take_minutes`.
- The app's committee dashboard links the page for chairs, and shows Upload /
  Manage members to members who've been given them.
