# Parliament v2.5.2 - Committee Minutes Editor

**Release Date:** January 29, 2026
**Status:** ✅ Deployed to Production
**Type:** Minor Feature Release - Committee Minutes

---

## Overview

Extends the Chapter Minutes editor to committees. Committees now have the full editor experience (motions, section headers/enders, attendance, PDF generation, publish) scoped to committee membership. Any committee member can create minutes, but only chairs, admins, and designated secretaries can edit after initial creation. Publishing creates a CommitteeDocument linked to the committee, with an option to also publish to Chapter Documents.

The implementation reuses the existing `ChapterMinutes` model by adding an optional `committee` FK, so all `MinutesSection`, `MinutesMotion`, and PDF generation infrastructure is shared with zero duplication.

## New Features

### 1. Committee Minutes Editor
Full-featured minutes editor for committees, adapted from the Chapter Minutes editor with committee-specific scoping.

- **Attendance** pulls from committee members + chairs (deduplicated), not all active members
- **Motion author dropdown** scoped to committee members
- **No event linking** (committees don't use the Event model)
- **No excuse integration** (committees don't track excuses)
- Reuses the `officer/chapter_minutes_editor.html` template with `is_committee_minutes` context flag for conditional rendering

**Views Created (`src/view/committee/committee_minutes_editor.py`):**
- `committee_minutes_list` — List all committee minutes (drafts and published)
- `create_committee_minutes` — Create a new committee minutes session
- `edit_committee_minutes` — Main editor page for committee minutes
- `save_committee_minutes_data` — AJAX endpoint to save sections (text + motions)
- `save_committee_minutes_attendance` — AJAX endpoint to save attendance
- `publish_committee_minutes` — Publish minutes as PDF to committee documents
- `download_committee_minutes_pdf` — Generate and download/preview PDF
- `delete_committee_minutes` — Delete minutes (editors delete drafts, admins delete published)

---

### 2. Committee Minutes List Page
New `templates/committee/minutes_list.html` page showing all committee minutes with:
- Date, time, status badges (Draft/Finalized/Published/Edited)
- Attendance taken indicator
- Creator name and time since last update
- "New Minutes" button for any committee member
- Delete button for editors (chairs/admins/secretaries)
- Create modal with title, date, and start time fields
- Delete confirmation modal with published minutes warning

---

### 3. Publish to Committee and/or Chapter Documents
When publishing committee minutes:
- Creates a `CommitteeDocument` with `document_type='minutes'` linked to the committee
- Visibility options: Committee Only or Public
- Optional "Also publish to Chapter Documents" checkbox sets `published_to_chapter=True`
- PDF title uses "Committee Minutes: {committee name}" format
- PDF subtitle shows committee name below the title

---

### 4. Committee-Specific PDF Titles
Updated `generate_minutes_pdf_buffer()` to detect committee context:
- Chapter minutes: "Chapter Minutes" title (unchanged)
- Committee minutes: "Committee Minutes: {committee name}" title with "Committee: {name}" subtitle

---

### 5. Data Isolation
Added `committee__isnull=True` filter to all existing chapter minutes views to prevent committee minutes from appearing in the chapter minutes list:
- `chapter_minutes_list`
- `edit_chapter_minutes`
- `save_minutes_data`
- `save_minutes_attendance`
- `publish_chapter_minutes`
- `download_minutes_pdf`
- `delete_chapter_minutes`

---

### 6. Dark Mode: Edit Channel Page & Edit Chat Settings
Added dark mode support to the "Edit Channel" page (`chat/edit_channel.html`) and the committee "Edit Chat Settings" page (`committee/edit_chat_settings.html`). All elements — form cards, inputs, labels, radio buttons, checkboxes, permission lists, helper text, and buttons — now use `dark:` variants.

**Files Changed:**
- `templates/chat/edit_channel.html` — Added dark mode classes throughout
- `templates/committee/edit_chat_settings.html` — Added dark mode classes throughout

## Permission Model

### Three-Tier Permissions

| Action | Who Can Do It |
|--------|---------------|
| **View minutes list** | Any committee member, chair, officer, or admin |
| **Create minutes** | Any committee member, chair, officer, or admin |
| **Edit own draft** | The original creator (draft status only) |
| **Edit any minutes** | Committee chairs, admins, designated secretaries (`can_take_minutes=True`) |
| **Publish minutes** | Committee chairs, admins, designated secretaries |
| **Delete draft minutes** | Committee chairs, admins, designated secretaries |
| **Delete published minutes** | Admins only |
| **Download PDF** | Any committee member, chair, officer, or admin |

### Permission Helpers

```python
is_committee_member_or_above(user, committee)
    # True if member, chair, officer, or admin

can_edit_committee_minutes(user, committee)
    # True if admin, chair, or has can_take_minutes=True

can_edit_specific_minutes(user, committee, minutes)
    # True if can_edit_committee_minutes OR creator of own draft
```

### Designated Secretary Permission
New `can_take_minutes` boolean on `CommitteePermissions` allows non-chair members to be granted full edit/publish access to committee minutes without being a chair.

## Database Changes

### Migrations in This Release
| Migration | Description |
|-----------|-------------|
| `0072` | Added `committee` FK (nullable) to `ChapterMinutes`, added `can_take_minutes` boolean to `CommitteePermissions` |

### Model Changes

**`ChapterMinutes`** — Added field:
```python
committee = models.ForeignKey(
    Committee, on_delete=models.CASCADE,
    null=True, blank=True,
    related_name='committee_minutes_sessions',
    help_text='If set, these are committee minutes; if null, chapter minutes'
)
```

**`CommitteePermissions`** — Added field:
```python
can_take_minutes = models.BooleanField(
    default=False,
    help_text='Designated secretary: can create/edit committee minutes'
)
```

### Migration Command
```bash
python manage.py migrate src 0072
```
