## 🟡 Resolution page: one query per amendment

**Reported by:** Mason, from the performance panel, 10-02-26: 15× the same
`src_section` query on `cnb/resolution_detail.html:239`.

Each amendment's "surrounding context" block loops the sibling sections of
its article (`amendment.section.article.sections.all`), and that relation was
not prefetched, so it cost one query per amendment.

**Fix.** `resolution_detail` also prefetches
`amendments__section__article__sections`. The page's query count no longer
grows with the number of amendments.

**Tests:** `DetailPageQueryCountTests` in `test_cnb_amendment_preview.py`
(same count with 2 and with 8 amendments; fails without the fix).
