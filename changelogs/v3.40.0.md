## 🟢 Original 1800s founders: Beta Blue class, hidden directory section

**Asked (Mason, 10-01-26):** the original 1800s founders (roll #1–#43) were
added for record keeping. Give them their own class color like the other
classes (Beta Blue) plus a script to apply it, don't let members claim it
themselves, and hide them in the directory unless asked for.

### What changed
- **Class color.** `src/pledge_classes.py` recognizes "Original Founders" in
  the stored class (or greek) text and returns a Beta Blue (`#003da5`) badge,
  "Original Founder Class", on the directory card, profile modal and house
  map. They sit outside the semester sequence: never in the class dropdown,
  never rewritten by `apply_to_fields` or `normalize_pledge_classes`. Beta
  Blue still clears the palette's ΔE > 10 test (nearest: `#2d35a9`, 10.2).
- **`mark_original_founders` command.** Sets `pledge_class` = "Original
  Founders" for roll #1–#43. They weren't all one semester; it's a nod.
  The greek field is untouched. Dry run by default; a roll-numbered member
  whose class already resolves to a modern semester is skipped and listed.
- **Not self-serve.** The member profile form rejects "Original Founder(s)"
  in either field (form and AJAX). Admin-v2 can still set it.
- **Directory.** Founders are pulled out of the Alumni list. Once alumni are
  shown, a second **Show Original Founders** toggle reveals them in their own
  section, in roll order. The directory export leaves them out.

### Tests
`src/tests/education/test_pledge_classes.py`: badge color, palette distance,
the command (dry run, roll range, clash skip, greek untouched), the profile
