## 🟢 Resolution edit page: a plain Save button

**Asked (Mason, 10-02-26):** "the edit page only has a save and preview
button, can you add just an edit button to save without previewing?"

**What was there.** The page did have a second button that saved without the
preview, but it was labelled "Edit Resolution" (the form's `{{ action }}
Resolution` label, which reads right on the create page and wrong on the edit
page), and it left for the resolution page after saving.

**Change.**
- On the edit page that button is now **Save**. It saves and **stays on the
  edit page**, so a working group can save as it goes.
- **Save & Preview** is unchanged. The create page still says "Create
  Resolution".
- `edit_resolution` redirects back to the edit page when the post carries
  `save_stay`; any other post behaves as before.

**Tests:** `src/tests/legislation/test_cnb_edit_save_button.py` (4).
