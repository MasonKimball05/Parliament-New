# v3.15.0 — QOL/UX batch (07-19-26)

Five member-facing quality-of-life improvements from the 07-19 review's UX
scan, picked by Mason (items 2–6; the ⌘K search shortcut was skipped).

## Dirty-form guard (minutes editor + legislation upload)

- `templates/officer/chapter_minutes_editor.html`: leaving with unsaved
  edits now triggers the browser's are-you-sure dialog. Edits set a dirty
  flag; any successful save to `SAVE_URL` or `ATTENDANCE_URL` clears it
  (both persist server-side), and submitting the publish form clears it
  (it does its own synchronous save first). Applies to both chapter and
  committee minutes (shared template).
- `templates/vote.html`: same guard on the two legislation upload forms
  (`data-dirty-guard`); any form submission on the page clears the flag so
  casting a vote isn't blocked.

## Recent Logins card on profile

- Profile → Security card → new "Recent Logins" accordion: last 5
  successful logins with timestamp, browser/OS, and city/region.
  Suspicious-flagged logins get a red "Flagged" badge; footer links to the
  active-sessions page. **The raw IP is never rendered** (it's encrypted at
  rest and city/region is friendlier anyway). One indexed query
  (`user.login_history.filter(status='success')[:5]`).

## PWA offline fallback

- `static/js/service-worker.js`: install now caches `static/offline.html` +
  the seal into `parliament-offline-v1`; a fetch handler intercepts **failed
  top-level navigations only** and shows the offline page. No app content is
  cached and non-navigation requests (API, POSTs, static) are untouched, so
  the original credential concerns don't apply. Old offline caches are
  cleaned on activate.
- `static/offline.html`: self-contained, dark-mode aware, **zero JS** (the
  "Try again" button is a plain link to `/home/`) so it's CSP-safe under any
  header regime.

## Add to Google Calendar

- `Event.google_calendar_url` property (`src/models/events.py`): Google
  quick-add link with UTC times and a 1-hour assumed duration (same
  assumption as the iCal export). No migration (pure property).
- Event modals on the calendar page (both the server-rendered and the
  JS-built variants) now show "Add to Google Calendar | Download .ics";
  the data API (`calendar_data_api`) gained `google_url` + `ics_url`.
  The per-event `.ics` endpoint already existed but was never linked in
  the UI until now.

## Auto-dismissing flash messages

- `templates/base.html`: success/info flashes fade out after 5 s with
  pause-on-hover; **error and warning flashes stay sticky** — they may
  need to be read carefully or acted on.

### Mobile pass (structural, static analysis)

- **19 tables across 17 templates wrapped in `overflow-x-auto`** — an
  unwrapped `<table>` forces the whole page wide on a phone; wrapped, only
  the table scrolls. Biggest member-facing wins: Constitution & Bylaws
  (3 tables), Robert's Rules; plus 10 admin_v2 pages, recruitment/candidate
  lists, service dashboard.
- Two content grids stacked on mobile (`grid-cols-1 sm:grid-cols-3`):
  vote_result voter-name columns, guide vote-options cards. Numeric-input
  trios and stat counters deliberately left 3-across (fine on phones).
- Verified fine: viewport meta, calendar min-width (inside its own
  scroller), modal `mx-4` gutters, nav search collapse.

### Mobile pass, round 2 — admin_v2 tables (Mason-reported pain point)

The wrapper alone wasn't the whole fix: a `w-full` table with wrappable
headers **shrinks to the phone's width and crushes its columns into
unreadable slivers** — the scroll container never engages. The working
pattern is wrapper + `min-w-full` + `whitespace-nowrap` headers, so the
table grows to its natural width and scrolls sideways instead. Applied
across **all 24 admin_v2 templates with tables** (30 tables): 22
`w-full → min-w-full` swaps, ~170 header cells nowrapped, every table
verified to have an `overflow-x-auto` ancestor. Also stacked the 2FA
dashboard bulk-actions bar on small screens (it overflowed). Cell (`td`)
content deliberately left wrappable so long values (user agents, URLs)
don't force absurd table widths.

### Accessibility

- Calendar event modals (both variants): `role="dialog"`,
  `aria-modal="true"`, `aria-labelledby` on the title, `aria-label` on the
  icon-only close buttons. Profile crop `<img>` got alt text. Nav bell +
  hamburger were already labeled.
