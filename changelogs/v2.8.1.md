# v2.8.1 - Mobile UI Fixes & VPP Access Fix

**Release Date:** March 16, 2026

**Deployment Status:** Ready for Deployment

## Overview

Bug fixes for mobile layout issues and VPP role access control improvements.

---

## Bug Fixes

### Mobile UI Fixes

#### Home Page Announcement URLs
- **Issue**: Long URLs in announcements would overflow off the page on mobile devices
- **Fix**: Added CSS word-break properties (`break-words`, `overflow-wrap: anywhere`) to announcement content
- **Files Changed**: `templates/home.html`

#### Committee Page Button Labels
- **Issue**: "All Committees" and "Admin: View All" buttons showed only "All" on mobile, making them indistinguishable
- **Fix**: Changed mobile labels to "Browse" and "View All" respectively
- **Files Changed**: `templates/committee/committee_index.html`

#### Committee Dropdown Positioning
- **Issue**: Dropdown menu was positioned off the left side of the screen on mobile devices
- **Fix**:
  - Changed to `fixed` positioning on mobile with `inset-x-4` (16px margin from edges)
  - Added semi-transparent overlay for better UX
  - JavaScript dynamically positions dropdown below button
  - Desktop retains right-aligned absolute positioning
- **Files Changed**: `templates/committee/committee_index.html`

#### Footer Mobile Layout
- **Issue**: Footer links and pipe separators stacked awkwardly on mobile
- **Fix**:
  - Hidden pipe separators on mobile (`hidden sm:inline`)
  - Used `flex-wrap` with `gap` for natural wrapping
- **Files Changed**: `templates/base.html`

### VPP Access Control Fixes

#### Case-Insensitive Role Check
- **Issue**: VPP role check was case-sensitive (`code='VPP'`), potentially missing roles stored with different casing
- **Fix**: Changed to case-insensitive check using `code__iexact='VPP'`
- **Files Changed**:
  - `src/decorators.py`
  - `src/view/service_user_dashboard.py`
  - `src/view/service_form_builder.py`

#### Decorator Improvements
- **Issue**: `vpp_required` decorator was missing `functools.wraps`, which could cause issues with function metadata
- **Fix**: Added `@wraps(view_func)` decorator
- **Files Changed**: `src/decorators.py`

## Code Changes

### templates/home.html
```html
<!-- Before -->
<p class="... whitespace-pre-wrap">{{ latest.content|linkify }}</p>

<!-- After -->
<p class="... whitespace-pre-wrap break-words overflow-wrap-anywhere"
   style="word-break: break-word; overflow-wrap: anywhere;">
    {{ latest.content|linkify }}
</p>
```

### src/decorators.py
```python
# Before
if request.user.roles.filter(code='VPP').exists():

# After
if request.user.roles.filter(code__iexact='VPP').exists():
```
