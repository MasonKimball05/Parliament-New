## Slating: ballots can't be traced back in the database

Slating votes were already kept apart from the record of who voted, with no
shared key, and the admin pages hid anything that could pair them up. But
anyone reading the database directly could still match them:

- **Timestamps.** Each vote stored the time it was cast, which matched the
  voter's "has voted" record to the microsecond.
- **Numbering.** Votes were numbered in the order they came in, so the 5th
  vote of a round belonged to the 5th person who voted.

Now:

- Votes have **no timestamp at all**.
- Votes are keyed by a **random ID** instead of a number.
- Votes already recorded, including Saturday's, lose their timestamps and
  get new random IDs. The table is then reordered by those IDs, so even its
  storage order no longer follows the order ballots were cast.

Nothing changes for members or the committee: who has voted, the counts,
rejection reasons, results and publishing all work as before.

**One thing to know:** database backups taken before this deploy still have
the old timestamps. If ballot secrecy for Saturday's election matters to
you, delete or lock down the older backups once a new one has been taken.

**For developers:** never add a creation time, a sequence, or anything else
ordered by casting time to `SlatingVote` (see the model's docstring). Tests:
`src/tests/slating/test_ballot_unlinkable.py`, including a run of the real
migration over existing votes.

## CI fixes (main was red after the 11-07 push)

- **Security scan:** the admin console's icon tag used `mark_safe`, which
  the bandit scan fails on. The icon shapes are fixed text that escaping
  doesn't change, so it's gone; a test checks every icon still renders the
  same.
- **Admin console query test:** the number of queries depended on whether
  the machine had Redis. With Redis the background-worker check errored and
  skipped reading the job schedule; on CI it didn't, one query more. The
  test now fakes that check, so every machine counts the same (classic
  dashboard 47, console 38).
