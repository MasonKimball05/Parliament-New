## `bug_tracker` N+1 on `submitted_by`

`bug_admin` (`/bug-tracker/admin/`) — the same `BugReport` list one tier
up, admin-only — already carries `.select_related('submitted_by',
'resolved_by').defer(*member_defer('submitted_by', 'resolved_by'))`. The
member-facing `bug_tracker` view never got the equivalent join; every row
on the page paid for its own `ParliamentUser` fetch instead.
`bug_report_detail` (the single-report page) was already correct too — this
was specifically the list view that was missed, apparently never
reconciled against `bug_admin` when that one was fixed.

**Fix:** `.select_related('submitted_by').defer(*member_defer('submitted_by'))`
on the `bug_tracker` queryset — `resolved_by` isn't rendered on this page
(only in the admin view), so it isn't joined here.
