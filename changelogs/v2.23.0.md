# v2.23.0 — Chair Appointment Votes

**Status:** Code-complete, not yet deployed
**Date:** 05-29-2026

---

## Summary

Officers can now nominate a member for a chair/role position by creating an appointment vote directly from the legislation page. The vote appears to the chapter like any other legislation. When it passes (either via live vote or manual entry), the author is prompted to formally assign the role and promote the member's account. The entire flow reuses the existing Legislation/Vote infrastructure — no separate appointment system.

---

## New Features

### Appointment Vote Creation
- New "Chair Appointment" tab on the legislation upload panel (tab toggles between "Upload Legislation" and "Chair Appointment" — officer-only)
- Officer selects a role from a dropdown (all `Role` objects), a nominee (active members), and vote settings (mode, threshold, dates, anonymous, abstain)
- Vote mode can be set to **percentage**, **piecewise**, or **plurality** — plurality allows multiple candidates in separate options (no single nominee required)
- Title and description are auto-generated if left blank (`"Chair Appointment: {name} as {role}"`)
- Appointment votes display an indigo **Appointment** badge + role name pill on the legislation card in the vote feed

### Role Assignment Prompt
- After a vote passes (both via auto-close and via manual "Mark as Voted"), officers are redirected to `assign_appointment` instead of the passed legislation page
- `assign_appointment` view renders a confirmation page showing the legislation outcome, the role, and (for non-plurality votes) the nominated member
- Plurality appointments show a dropdown to select the winning candidate from active members
- Submitting assigns the role via `member.roles.add(role)`, promotes `member_type` to `Chair` if currently `Member`, and sets `appointment_assigned = True` on the legislation
- "Skip for Now" button lets officers defer the assignment — the passed legislation page shows a persistent green callout for any passed but unassigned appointments

### Passed Legislation Callout
- `passed_legislation.html` shows a banner at the top of the page for each passed appointment vote where `appointment_assigned = False`
- Banner links directly to the `assign_appointment` view

## Model Changes

Four new fields added to `Legislation`:

| Field | Type | Purpose |
|-------|------|---------|
| `legislation_type` | `CharField` (choices: `general`, `appointment`) | Distinguishes appointment votes |
| `appointment_role` | `ForeignKey(Role, null=True)` | The role being filled |
| `appointment_member` | `ForeignKey(ParliamentUser, null=True)` | Nominated member (null for plurality) |
| `appointment_assigned` | `BooleanField(default=False)` | Whether role has been formally assigned |

Migration: `0174_legislation_appointment_fields`
