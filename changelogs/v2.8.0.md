# v2.8.0 - Service Hours System & Directory Export

**Release Date:** March 16, 2026

**Deployment Status:** Ready for Deployment

---

## Overview

Comprehensive service hours tracking system for members and VPP officers, plus directory export functionality.

---

## Key Features

### Service Hours System

#### Member Features
- **Service Hours Dashboard**: Personal dashboard showing progress toward service hour requirements with submission history
- **Submit Hours**: Members can submit service hours with date, organization, description, hours, and optional proof/documentation
- **Edit Submissions**: Members can edit pending or rejected submissions
- **Progress Tracking**: Visual progress bar and statistics showing approved, pending, and remaining hours

#### VPP Officer Features
- **Officer Dashboard**: Analytics dashboard with submission statistics and member progress overview
- **Service Periods**: Create and manage service periods with configurable hour requirements and approval settings
- **Member Expectations**: Set default hours per period with individual member overrides (exemptions, increased requirements)
- **Submission Management**: Approve, reject, or request changes on submissions with reviewer notes
- **Bulk Actions**: Bulk approve/reject multiple submissions
- **CSV Export**: Export submission data for external use

#### Form Builder
- **Custom Fields**: VPP can add custom fields to the submission form (text, number, date, select, file upload, etc.)
- **Built-in Fields Display**: Form builder shows all fields including built-in ones (period, hours, date, organization, description, attachment)
- **Field Editing**: Edit labels, help text, required status, and placeholders for all fields
- **Built-in Protection**: Built-in fields can be edited but not deleted

### Directory Export
- **Multiple Formats**: Export member directory to CSV, TXT, or Excel (.xlsx) formats
- **Data Included**: Names, emails, phone numbers, member types, and roles
- **Excel Styling**: Excel exports include formatted headers and auto-sized columns

## Database Changes

### New Models

| Model | Purpose |
|-------|---------|
| `ServicePeriod` | Defines service hour periods with date ranges and requirements |
| `ServiceMemberExpectation` | Individual member hour requirement overrides |
| `ServiceHoursSubmission` | Hour submissions with approval workflow |
| `ServiceFormField` | Custom form field definitions (with `is_builtin` flag) |
| `ServiceFieldResponse` | Custom field response storage |
| `ServiceActivity` | Audit logging for submissions |

### Member URLs
| URL | View | Description |
|-----|------|-------------|
